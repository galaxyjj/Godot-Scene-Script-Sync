# Godot-Scene-Script-Sync
## 简介
## Descript
### 切换场景页签时，脚本编辑器自动切换到当前场景根节点的脚本。方便在多个场景间快速切换编辑脚本，手动切换脚本时不会影响场景选择。
### Automatically switches the script editor to the root node's script when switching scene tabs. Quickly navigate between scene scripts without manual switching. Manually changing scripts does not affect scene selection.

## 用法
## Usage
### 将"quick_pick_scripts"文件夹放入Godot项目的"addons"文件夹中,并在项目设置的插件中启用插件即可
### Place the "quick_pick_scripts" folder into the "addons" folder of your Godot project, and enable the plugin in the plugin settings of your project
